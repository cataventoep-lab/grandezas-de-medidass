Medidas de Grandezas

Escolha uma grandeza, caminhe pelo cenário 3D e desvende os mistérios escondidos nos objetos do dia a dia.

0 de 0 estrelas
Como jogar
  1. Toque ou clique no chão para a sua personagem andar. No computador, também dá para usar as setas ou W, A, S, D.
  2. Arraste a tela para girar a câmera. Use a rodinha do mouse ou o gesto de pinça para aproximar.
  3. Procure os pontos de interrogação amarelos. Toque neles para abrir um mistério.
  4. Leia a pergunta, observe o objeto e escolha a resposta. Se errar, peça uma dica e tente de novo.
  5. Cada mistério resolvido vale uma estrela. Resolva todos para ganhar a medalha do mundo.
